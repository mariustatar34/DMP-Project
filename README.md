# DMP-Project
This project uses an ESP32-S3 to monitor the soil moisture of a plant and automatically water it when needed. The system also checks the water lvl in the reservoir, controls a small pump, and displays the current status on an OLED screen.

Features
- soil moisture monitoring
- automatic plant watering
- water reservoir level detection
- protection against running the pump when the reservoir is empty
- manual watering using a push button
- OLED display for system information
- buzzer and LED status indications
- ESP32-S3 as the main controller
- Wi-Fi?

Components
- ESP32-S3 board
- soil moisture sensor
- OLED display
- mini water pump
- MOSFET module
- water level float sensor
- push button
- buzzer
- two LEDs red and green
- 5V power supply
